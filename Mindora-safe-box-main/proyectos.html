Proyectos Mindora Safe Box

Muestra casos de éxito o trabajos realizados.

Proyecto 1: Sistema web

Desarrollo de una plataforma web que permite el registro y control del préstamo de útiles escolares. El sistema gestiona usuarios mediante identificación institucional, registra préstamos y devoluciones, y lleva un historial que facilita el seguimiento y la organización de los recursos.

Proyecto 2: Automatización

Diseño de un locker inteligente para el almacenamiento y préstamo seguro de útiles escolares. El sistema funciona mediante identificación del estudiante y sensores que detectan el uso de los compartimentos, garantizando un control eficiente y ordenado.

Proyecto 3: Dashboard

Implementación de la conexión entre la plataforma web y el locker automatizado. Cada acción realizada queda registrada en tiempo real, permitiendo un control preciso y evitando pérdidas o usos indebidos de los útiles.

Proyecto 4: App

Proyecto orientado a mejorar la equidad en el entorno educativo, asegurando que los estudiantes tengan acceso oportuno a los útiles necesarios. Además, promueve la responsabilidad y el uso consciente de la tecnología dentro de la institución.
